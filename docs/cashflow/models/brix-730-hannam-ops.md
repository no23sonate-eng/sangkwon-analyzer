## 1. 사업 개요

- **사업**: 서울 용산구 한남대로 27길 14 (한남동 730번지 일원) **시니어 레지던스(노인복지주택) 개발·운영**
  - 용도: 노유자시설(노인복지주택) + 근린생활시설 + 운동시설, 제2종 일반주거지역, 고도지구(28m), B5/7F
  - 대지 6,673㎡(2,018.6평), 연면적 39,569㎡(11,969.7평), 건폐율 59.3%, 용적률 249.2%
  - **노인복지주택 111세대** (99A 65 / 99B 16 / 99C 24 / 108 6세대), 입주민 177명 가정
  - 근린생활시설 5,910㎡(일부 리테일 선매각), 운동시설 1,995㎡ (B1 피트니스·수영장·사우나·골프연습장, B1 의원/웰니스)
- **기간**: 분석 기준일 2026-01-01 / 공사 2026-01~2028-12 (35개월) / 운영 개시 2028-12-31 / 처분 2030-12-31 (Vehicle 운영 59개월). IS는 FY2029~FY2036까지 산출.
- **투자 규모**: 개발원가 570,000백만원(5,700억), Equity 56,000백만원 (IS_Prop.Co. F66:G67)
- **Prop.Co. / OpCo. 이중 구조**:
  - **Prop.Co.(설치자, 부동산 보유회사)**: 자산 보유. 모든 시설 매출(GOR)을 인식하고, 자기 비용(수선유지·보험·유틸리티·제세공과·운영예비비)과 아래 수수료를 부담.
    - → OpCo에: **위탁운영비용(실비 100% reimburse) + 위탁운영수수료(총매출의 3%) + Incentive Fee(AGOP의 4%)**
    - → 호텔 운영사(파르나스 계열 추정): **기본수수료(총매출의 2%) + Incentive Fee(AGOP의 5%)**
    - → AM사: **AM Fee(총사업비의 0.08% ≒ 연 500백만원)**
    - Reserve FF&E: 총매출의 1.5%
  - **OpCo.(위탁운영회사)**: 매출 = Prop.Co.로부터 받는 실비+수수료+인센티브. 비용 = 인건비, 일반관리비(린넨·소모품), 헬스케어 멤버십 원가, 매출원가(F&B·피트니스·웰니스·공간대여). 실비는 pass-through이므로 **OpCo EBITDA = 위탁운영수수료 + Incentive Fee** (2029년 528.4백만원).
  - 운영사업 내용: **시니어 주거서비스(컨시어지·객실·발렛) + F&B(입주민 식당·티하우스) + 피트니스 멤버십 + 메디컬 멤버십(차움/차헬스케어 연계 헬스케어 라운지, 건강검진) + 의원(임대)**.
