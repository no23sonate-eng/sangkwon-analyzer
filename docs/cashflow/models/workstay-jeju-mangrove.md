# BRIX × WORKSTAY(맹그로브 제주시티) Financial Model v7.3 — 상세 분석

**모델 유형**: 제주시 삼도이동 1192-2 노후건물 매입·리모델링 후 맹그로브(MGRV) "워크스테이" 호텔에 10년 마스터리스(MRG+매출연동) + 리테일 전대하는 **밸류애드 임대운영(SPC) 재무모델** — 개발 CF, 리파이낸싱, 운영실적 피드백, 주주 waterfall까지 통합.

- **사업수지/TIC 대분류**: 토지관련비(11,544백만, 48.8%) / 공사비(9,183백만, 38.9% = 직접 8,533 + 간접 634) / 부대비·제세공과금(281) / 용역수수료(52) / SPC관련비용(1,730, AMC·PM Fee·TI 포함) / 금융비용(726) → **총 TIC 23,639백만원(236억, 평당 13.19백만)**; 조달 = Equity 80억 + 시설대 170억 @5.8% + 보증금 5억 (리파 후 190억 @4.45% + Equity 60억 감자)
- **호텔 운영 가정 핵심값**: 객실 90실(멤버십 18 + 일반 72), ADR 90,000/105,000원(+2%/년), OCC 램프업 FY1 67%→FY4 88%, 임대료 = **MAX(MRG 연 7억, 객실매출 38% + 부가매출 6~43% 연동)**, 렌트프리 6개월, OTA 수수료 16%, F&B 원가 70%, 인력 CM 5 + FM 14~16명 — 운영사 EBITDAR 마진 Y3 46.4%, 임대료율 매출의 36.6%
- **수익률 지표**: FY2026 NOI 1,509백만 / DSCR 1.79 / CoC 10.1%→12.9%; '26.2월 조기매각 279억 시 **Equity IRR 14.47%** (세후 11.7%; 헬리녹스 5년 재계약 전제 — 2년 연장 11.5%, 미체결 9.0%), 분배 90.3억을 라펠:헬리녹스 50:50; Terminal cap 6.0%, FY5 exit 345억, AMC 성과보수 12.4억(+매각성과보수 10%). 2025 실적은 계획 초과(Occ 79.5% vs 76.4%, ADR 94,635 vs 84,736원, 매출 27.4억).

## 1. 프로젝트 개요
- **프로젝트명**: 제주 삼도이동 1192-2 맹그로브 제주시티 임대운영 사업
- **본질**: 밸류애드(리모델링) + 호텔 마스터리스. SPC가 건물 매입·리모델링 후 2~8F(관광호텔부 1,479.87py)를 MGRV(맹그로브)에 10년 임대 — 맹그로브가 코리빙/워케이션 호텔(객실 90실 + 코워킹 + 멤버십)로 운영. 1F·B1 리테일(살로몬·올버즈·헬리녹스)은 전대 구조. SPC는 직영이 아닌 임대인.
- **물건**: 제주시 삼도이동 1192-20 (일반상업지역), B1/7F+옥탑, 대지 1,175㎡(355.44py), 연면적 5,924.22㎡(**1,792.08py**, 지상 4,782/지하 1,142), 건폐율 59.5%, 용적률 4.07, 사용승인 2024-10-29
- **타임라인**: SPC설립·토지계약 2022-12-19 → 공사 2024-01~10(10개월) → 임대운영 2024-11-18~2029-11-30(60개월, 호텔 RF 6개월 ~'25-05-05) → **리파이낸싱 2025-11-30** → 당초 매각 2029-11 (현재 검토: **2026-02-28 조기매각 @279억**). 사업기간 83개월(6.9년), REF 후속 8년(~2037-11) 가정.
- **조달**: 최초 255억 = 보증금 5억 + 시설대 170억(66.7%) + **자본금 80억(31.4%)**; 리파 후 255.5억 = 보증금 5.5억 + 신규대출 190억 @4.45% + 자본금 60억('25.12 감자 −20억). 담보평가(준공후) 330억, LTV 57.6%.
- **주주 구조**: SPC 보통주 **라펠 50% : 헬리녹스 50%** (헬리녹스는 B1 임차인 겸 주주 — 임대차 연장이 매각가·IRR 핵심 변수). AMC = 브릭스.
