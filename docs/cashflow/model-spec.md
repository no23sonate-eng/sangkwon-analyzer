## 2. 공통 시트 아키텍처 (4건 공통)

1. **Log / 변경사항** — 버전 이력 (v6.9까지 17건 식으로 누적. 모델 신뢰성의 근거)
2. **A&R** (Assumptions & Results) — 가정 허브 + 결과 요약 + **Check 로직**(현금부족/청산완료/합계일치 True/False)
3. **사업수지 / TIC** — 총투자비 라인아이템 트리 (§3). 항목마다 산정방식(요율·단가·일식·기간×월액)과 지급 기점~종점 명기
4. **Dev.CF(M)** — 개발기간 월별 CF (§4). 열=월(사업착수~청산), 행=잔액→Cash In(조달)→Cash Out(원가)→조달 롤포워드
5. **RentRoll / Area / Unit_Price** — 수입 단가 근거 (§5)
6. **운영가정 / NOI / IS** — 운영기간 수입·비용 엔진 (§6)
7. **CF(M) 운영 / CF(Y)** — 운영기간 CF + Exit + Unlevered/Levered CF (§7)
8. **Tax** — 취득세·재산세·종부세·국민주택채권·매입세액 안분 월별 엔진 (§8)
9. **Loan 민감도 / 시나리오 시트** — 분양률·임대율·재계약 변형 (§9)
10. **투자자수익률** — equity waterfall, 주주별 XIRR (§7.3)

**단위 규약**: 개발모델 천원 / 운영 IS 백만원 / 세부 근거시트 원. 시트 상단에 단위 명기.
**시점보정**: 단가는 견적 시점(예: 2026) 기준 입력 → 운영개시 연도로 상승률 보정해 IS 투입.

## 4. 개발기간 CF 엔진 규칙

1. **조달 순서(waterfall)**: Equity 선투입("필수사업비 확보" 검증) → 부족분을 Tr.A → Tr.B → Tr.C(계정대) 순 한도인출. 브릿지 → 본PF → 준공 후 담보대출(리파) 3단계 치환.
2. **이자**: 월리 = 연리/12. Tr.A·B는 미지급 누적 → **3개월 주기 지급**, Tr.C 매월. 미인출 한도잔액에 **미인출수수료 연 0.5%**.
3. **공사비 지급**: 도급 = '공사진행율' **S-curve** lookup + 2개월 후불. 인입 6개월·인테리어 3개월 후불 등 항목별 지급조건.
4. **분양수입 계좌 워터폴**(분양형): 분양률 20%까지 [상환계좌 70%/운영계좌 30%] → 초과분 [94/6] → 준공 후 [100/0]. 운영계좌 = 분양불사업비 재원.
5. **납입 스케줄**(분양형): 계약금 1.7~10% / 중도금 회차별 10% / 잔금(준공 후) 나머지. 분양곡선: 개시 후 12개월 완판 (월 20-20-20-5…%).
6. **Check 행**: 기말잔액 음수 금지, TIC-CF 합계 일치, 청산완료 — G열 True/False 자동 검증.
7. **Call 금액 블록**: 향후 3개월 소요 사업비 + buffer로 출자·인출 요청액 산정 (soho).

## 5. 수입(임대·분양가) 산정 패턴

- **호실별 unit price** (분양형): 기준 평당가 × 지수 곱 — 층(2F 0.96 ~ 7F 1.05) × 타입 × 동·라인(한남대로 1.02/이면 1.01) × 간섭(옹벽 0.95~非간섭 1.03) × 향·조망. 기준 평당가는 PF 기준가액 충족 목표 역산 가능.
- **보증금 전환**: 전환보증금 = 월임대료 × 12 ÷ 전환율 5%.
- **마스터리스 임대료 역산** (soho 패턴): 기본임대료 = 원 개발원가 × cap 6.5% / 추가임대료(임차인 요구 CAPEX) = 투입비 × 6.67%(15년 회수) → Term Sheet 확정액과 크로스체크. Exit cap(5.3%)과의 **positive spread가 이익의 원천**.
- **MRG vs 매출연동** (workstay 패턴): 납부임대료 = MAX(MRG, Σ 매출부문별 연동율) — 객실 38%, F&B 15%, 기타 43% 등. 운영사 EBITDAR로 지속가능성 역검증(임대료/매출 35~40% 상한).
- **크로스체크 블록**: 임대료 ÷ 예상매출 = 부담률(42% 등)을 A&R 우측에 병기. ADR×OCC×객실수로 매출 추정.

## 6. 운영기간 모델 규칙

- **손익 트리**: GOR(부문별 매출) → 영업비용 → **NOI** → Reserve FF&E → **AGOP** → 영업외(Incentive·AM Fee) → **EBITDA**.
- **Prop.Co./OpCo. 분리**: OpCo 비용 100% 실비 정산(pass-through) + 위탁운영수수료(총매출 2~3%) + Incentive(AGOP 4~8%) → OpCo EBITDA = 수수료+인센티브만 잔존. 호텔 브랜드: 기본 2% + AGOP 5% (특정 부문 제외 가능).
- **표준 수수료**: Reserve FF&E 총매출 1.5% / Brand·Marketing Fee 1.5% / AM Fee 총사업비 0.08%/년.
- **상승률**: 매출·비용 일괄 **연 2.5%** (임대계약은 2~3%/년, 상승 개시 연차 명시 — soho는 5년차 개시·3년차 고정).
- **램프업**: 임대 55→85→100%(연차) 또는 OCC 67→77→86→88%(호텔). 렌트프리/fit-out 6~7개월.
- **Turnover vacancy**(멀티테넌트): 재계약확률 60% × downtime 4개월 / 임대기간 60개월 → 공실률 3%.
- **인건비 모델**: 본부>팀>직급 × 인원 × 계약연봉 + 4대보험(~10%) + 퇴직충당 1/12 + **외주수수료 5%**. 직접귀속 후 공통경비(경영지원·시설관리)는 면적비 재배분.
- **공통경비 안분 기준 3종**: ①부과면적배분(수선·보험·일반관리) ②전용면적배분(제세·Reserve·AM Fee) ③차등단가(유틸리티 — 피트니스 11,000원/평/월 vs 일반 2,000원). 단일배분(행사비→주거서비스 100% 등) 병용.
- **평당 운영비 단가**(원/월/평, 2026): 수선유지 1,000 / 보험 300 / 유틸리티 3,500 / 일반관리비 8,675.
- **triple-net 여부 명시**: 보유세·부담금 임차인 부담이면 운영 CF에서 0 처리 (soho).

## 7. Exit·수익률 규칙

1. **매각가 = forward NOI(N+1) ÷ terminal cap** (5.3~6.0%). 임대료 원천별 분해 표기(기본분 vs 추가분 — 자본화 인정 여부가 딜 쟁점).
2. **매각대금 분배**: 매각가 − 매각비용 − 기본보수 − 성과보수 → 대출상환 → 보증금 반환 → Capex reserve·청산비 → 잔여재산분배.
3. **Equity waterfall**: 우선주 우선배당(1종 4.6%, 2종 누적 7.0%) 분기 지급 → 청산배당. 주주별 실출자일 기준 **XIRR**. 세전/세후 병행.
4. **표준 아웃풋 지표**: 사업이익·이익률 / Unlevered·Levered IRR·MoM / 주주별 IRR / NOI·yield on cost / DSCR(min·max) / CoC / LTV·LTC / EBITDA·마진 / 대주 Exit 분양률.
5. **분배가능이익 체크**: 상법 배당재원(이익준비금·이월잉여금) 롤포워드로 배당 실행가능성 검증 (soho).

- 토지 재산세: 공시지가(상승률 5년 기하평균 6.3~7.1%/년) × 공정시장가액 70% × 별도합산 구간세율 0.2/0.3/0.4% + 도시지역분 0.14% + 지방교육세 20%. 용도 감면(노유자 25%) 반영.
- 종부세: 공제 80억, 0.5/0.6/0.7% 구간 + 농특세 20%.
- 건물 재산세: 신축단가(770~840천원/㎡, +2.6~3.2%/년) × 구조·용도·위치 지수 × 잔가율 × 70% × 0.25% + 도시지역분 + 지역자원시설세 + 교육세.
- 매입세액 불공제: 토지:건물 안분(면적·기준시가 비율) — 면세사업(주거) 비율 반영.
- 간주임대료 부가세: 보증금 × 정기예금이자율 3.5% × 10%.

## 9. 시나리오·민감도 표준

- **분양형**: 분양률 배율(100/50/20/0%) × 납입 스케줄(중도금 2회 vs 5회) 조합 시트 복제 → 상환부족액 산출 → 미분양 담보대출 Exit(감평 × LTV 50%)로 연결.
- **임대형**: 핵심 임차인 재계약(5년 재계약/2년 연장/미체결) × 매각가 → IRR 3안. 임대료 인상 vs 자산가치 증분 비교표(임차인 겸 주주 이해상충 정량화 — workstay).
- **공통**: 이자 증가분, cap rate ±, 성과임대료 인정률(100/50/0%).

## 10. 실적 피드백 루프 (workstay 패턴 — 운영 중 자산)

월별 운영실적(Occ·ADR·RevPAR·부문매출) 입력 → 매출연동 임대료 재산출 → **익년 Forecast = 당년 실적 × (1+상승률)** → CF·매각가·IRR 재산출. 예산 vs 실집행(CF Actual_TIC) 비교 시트 병행. 타지점·경쟁시설 벤치마크(클래식500, 나인원한남, Como) 열을 두고 "적정/부족" 판정.

## 신규 캐쉬플로우 작성 체크리스트

1. 유형 분기(§1) → 골격 모델 선택
2. A&R에 물리 가정(대지·연면적·전용률·용도별 면적) + 일정(인허가/공사/운영/매각 개월수) 확정
3. TIC 트리(§3)를 요율표로 채우기 — 근거 없는 항목은 학습 요율 기본값 + `추정` 표기
4. 조달 구조(§4): Equity/트랜치 금액·금리·선취, 단계(브릿지→PF→담보) 정의
5. 수입 엔진(§5): 분양가 지수표 or 임대료 역산 or MRG/연동 — 반드시 크로스체크 블록 포함
6. 운영 모델(§6): 램프업·렌트프리·상승률·수수료 체계
7. Exit(§7): terminal cap, 보수 체계, waterfall
8. Tax(§8) 월별 엔진 연결
9. 시나리오(§9) 최소 3안 + Check 로직 + Log 시트
10. 단위·시점보정 명기, 아웃풋 지표 표준셋(§7.4) 산출
