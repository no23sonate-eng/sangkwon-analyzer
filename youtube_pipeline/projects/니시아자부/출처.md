## 0. 먼저 읽을 것

### 대본 링크 ≠ 영상 소스

대본에 붙은 링크는 **숫자와 사실의 근거**다. 후생노동성 PDF, 법령 페이지,
통계 자료 같은 것. 화면에 띄울 그림이 아니다.

### 소스 우선순위 (채널 규칙)

| 순위 | 소스 | 조건 |
|---|---|---|
| ① | 브랜드 공식 유튜브·SNS | 출처 자막 상시 노출, 연속 인용 15초 이내 |
| ② | 보도자료·Press Kit·공식 뉴스룸 이미지 | 배포 목적물이므로 사용 가능. 출처 표기 |
| ③ | Google Maps 3D · Earth Studio | 출처 표기 |
| ④ | Pexels · Pixabay | 무료 |
| ⑤ | 유료 스톡 (Storyblocks / Artgrid / Envato) | |
| — | **직접 촬영** | **전체의 20% 이하** |

### 절대 금지

- **타 유튜버 영상 무단 인용**
- **유료 스톡의 무료 워터마크본**
- **뉴스 기사 본문 통 캡처** — 헤드라인 + 매체명 + 날짜만
- **영화 『JM』 포스터·스틸** (4장) — 저작권. **대사 자막만**
