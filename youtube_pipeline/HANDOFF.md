# 인수인계 — 새 Claude Code 세션은 이 문서부터 읽을 것

사용자는 비개발자다. 코드 설명 없이 결과 중심으로, 한국어로 소통한다.
질문받으면 선택지를 늘어놓지 말고 추천안 하나로 진행한다.

## 이 프로젝트가 뭔가

유튜브 편집 자동화 파이프라인 (`youtube_pipeline/`). 사용자(공간·부동산·브랜드
콘텐츠 채널 운영)가 찍은 말하는 영상을 넣으면: 전사 → B-roll 검색/검토 →
자막 스타일링/검토 → 렌더 → 프리미어/캡컷 내보내기까지 자동화한다.

- 실행: `python3 youtube_pipeline/app.py` → localhost:8500 웹앱 (사용자는 이것만 씀)
- 단계별 CLI도 독립 실행 가능 (`pipeline/*.py <프로젝트명>`)
- 전 과정 E2E 검증 완료 (2026-07-02, 원격 세션)

## 핵심 설계 원칙 (바꾸지 말 것)

1. **AI 판단 기준은 코드에 하드코딩 금지** — 반드시 `style_guide.md`를 프롬프트에
   주입. 톤/스타일 변경 = 그 문서 수정.
2. **style_guide.md는 사용자 채널 영상 4편을 실측 분석해 작성됨** — 자막 2계층
   (한 줄 본문 자막 + 대형 키워드 타이포), 강조색 레몬 옐로 #FAFF2E(실측),
   폰트 에이투지체(A2Z, assets/fonts, 웨이트별), B-roll 톤앤매너(시네마틱·다큐,
   기업 홍보 스톡 금지), 컷 리듬 2~5초.
3. **자막은 반드시 한 줄** (최대 20자, 긴 문장은 단어 타임스탬프로 큐 분할).
4. **검토 페이지에서의 사용자 수정은 feedback_log.json에 자동 누적**되고,
   다음 AI 호출 프롬프트에 주입된다 (취향 학습 루프). 이 흐름을 깨지 말 것.
5. `glossary.txt` = 고유명사 사전 (전사 힌트 + 띄어쓰기 보호 + 오인식 복원).
   사용자가 지명/브랜드를 계속 추가한다.

## 환경 메모

- `.env` (git 제외): PEXELS_API_KEY, PIXABAY_API_KEY 는 발급됨(사용자 보유),
  ANTHROPIC_API_KEY 는 **아직 없음** — 없으면 전 단계가 휴리스틱으로 폴백된다.
  키가 들어오면 keyword 추출·비전 톤 큐레이션·자막 스타일링·타이포 선정이
  실제 AI 판단으로 전환된다. 모델: claude-sonnet-4-6 (config.yaml).
- Whisper 모델: huggingface 접속되면 자동 다운로드. 막힌 환경이면
  `python youtube_pipeline/scripts/setup_model.py small-int8` (GitHub 릴리스 우회).
- 웹앱은 각 단계를 서브프로세스로 실행한다 (스레드 내 whisper 불안정 이슈 있었음).

## 알려진 남은 일 (우선순위 순)

1. ANTHROPIC_API_KEY 입수 후 AI 경로 실검증 (특히 displays 프롬프트 응답 파싱)
2. 사용자 실제 영상(9~11분)으로 전체 파이프라인 첫 실전 — 긴 영상에서
   구간/커버리지/전사 품질 점검
3. premiere.xml 을 실제 프리미어에서 가져오기 검증 (경로 relink 흐름)
4. 쇼츠(세로 1080x1920) 렌더 프로파일 실작동 테스트 (config에 구조만 있음)
5. BGM 덕킹, 원커맨드 실행 등 (사용자와 논의된 후보)

## 대화 톤 참고

사용자 호칭 없음/반말 섞임, 빠른 실행 선호. "어떻게 하라는거야" = 설명이
복잡했다는 뜻이니 클릭 단위로 다시. 스크린샷을 자주 보내니 이미지로 안내.
