# 인수인계 — 새 Claude Code 세션은 이 문서부터 읽을 것

사용자는 비개발자다. 코드 설명 없이 결과 중심으로, 한국어로 소통한다.
질문받으면 선택지를 늘어놓지 말고 추천안 하나로 진행한다.

## 이 프로젝트가 뭔가

유튜브 편집 자동화 파이프라인 (`youtube_pipeline/`). 사용자(공간·부동산·브랜드
콘텐츠 채널 운영)가 찍은 말하는 영상을 넣으면: 전사 → B-roll 검색/검토 →
자막 스타일링/검토 → 렌더 → 프리미어/캡컷 내보내기까지 자동화한다.

- 실행: `python3 youtube_pipeline/app.py` → localhost:8500 웹앱 (사용자는 이것만 씀)
- 단계별 CLI도 독립 실행 가능 (`pipeline/*.py <프로젝트명>`)
- 전 과정 E2E 검증 완료 (2026-07-02, 원격 세션)
- **첫 실전 제작 완료 (2026-07-09)**: `projects/외국인환자/` — 대본만 받아
  TTS 대역 나레이션으로 타이밍을 잡고, 세계지도(한국 하이라이트)·그래프 카드·
  Pexels 실사·대형 타이포 2종으로 29초 영상을 완성. 이 프로젝트 폴더가
  "완성 상태의 정답 예시"다 (계획 JSON들의 reason 필드에 판단 근거 기록됨).

## 핵심 설계 원칙 (바꾸지 말 것)

1. **AI 판단 기준은 코드에 하드코딩 금지** — 반드시 `style_guide.md`를 프롬프트에
   주입. 톤/스타일 변경 = 그 문서 수정.
2. **style_guide.md는 사용자 채널 영상 4편을 실측 분석해 작성됨** — 자막 2계층
   (한 줄 본문 자막 + 대형 키워드 타이포), 강조색 레몬 옐로 #FAFF2E(실측),
   폰트 에이투지체(A2Z, assets/fonts, 웨이트별), B-roll 톤앤매너(시네마틱·다큐,
   기업 홍보 스톡 금지), 컷 리듬 2~5초.
3. **자막은 반드시 한 줄** (최대 20자, 긴 문장은 단어 타임스탬프로 큐 분할).
4. **검토 페이지에서의 사용자 수정은 feedback_log.json에 자동 누적**되고,
   다음 AI 호출 프롬프트에 주입된다 (취향 학습 루프). 이 흐름을 깨지 말 것.
5. `glossary.txt` = 고유명사 사전 (전사 힌트 + 띄어쓰기 보호 + 오인식 복원).
   사용자가 지명/브랜드를 계속 추가한다.
6. **디자인 체계는 `design_reference.md`** — 셜록현준·조승연(탐구생활) 채널을
   실측 분석해 정리한 카탈로그 (색 체계, 텍스트 컴포넌트, 자료화면 연출 5종,
   컷 리듬, 금지 목록). 자료화면·타이포·그래프를 만들 땐 이 문서 기준.
   크기 위계 원칙: 작은 건 작게, 강조도 조금만 크게 (large 는 영상 전체 2~3문장).
   모션그래픽 금지 — 크로스페이드 + 사진 Ken Burns 만. (그래프의 화살표/포인트
   요소만 향후 예외 후보)
7. **자료 이미지는 풀블리드 금지** — 프레임 카드 연출 (render.py photo_frame,
   밝기에 따라 웜 페이퍼/딥 차콜 배경 자동). 영상 B-roll 만 풀블리드.
   대형 타이포는 얼굴 컷 위에만 — 자료화면과 겹치면 렌더에서 자동 제외된다.
8. **고퀄 소스 라이브러리 `pipeline/assets_lib.py`** — Wikimedia 고해상 이미지
   (라이선스/출처 credits.json 자동 기록), Iconify 픽토그램(인포그래픽 팔레트
   착색), 플랫 지도(세계/한국 시·도, matplotlib). 그래프는 아직 수제
   (외국인환자 사례처럼 infographic 팔레트 + A2Z 폰트로 matplotlib 직접 작성).

## 환경 메모

- `.env` (git 제외): PEXELS_API_KEY, PIXABAY_API_KEY 는 발급됨(사용자 보유),
  ANTHROPIC_API_KEY 는 **아직 없음** — 없으면 전 단계가 휴리스틱으로 폴백된다.
  키가 들어오면 keyword 추출·비전 톤 큐레이션·자막 스타일링·타이포 선정이
  실제 AI 판단으로 전환된다. 모델: claude-sonnet-4-6 (config.yaml).
- Whisper 모델: huggingface 접속되면 자동 다운로드. 막힌 환경이면
  `python youtube_pipeline/scripts/setup_model.py small-int8` (GitHub 릴리스 우회).
- 웹앱은 각 단계를 서브프로세스로 실행한다 (스레드 내 whisper 불안정 이슈 있었음).
- ANTHROPIC 키가 없는 동안은 **대화 중인 Claude 가 AI 판단을 대행**해도 된다
  (키워드 추출·후보 큐레이션·자막 스타일링·타이포 문안). 외국인환자 프로젝트가
  그 방식으로 만들어졌다 — 단, 판단 근거를 계획 JSON 의 reason 에 남길 것.
- split_long_cues 는 Whisper 단어(선행 공백 포함)와 외부 정렬 transcript
  (공백 미포함) 둘 다 지원 (2026-07-09 수정). 대본 기반 타이밍을 쓸 땐
  호흡 지점(쉼표 뒤)에 0.15~0.2초 단어 간격을 넣어주면 분할점이 자연스럽다.

## 알려진 남은 일 (우선순위 순)

1. **다음 세션에서 바로 반영할 것 (2026-07-09, 사용자 지적 — 아직 미반영)**
   - `source.mp4`(TTS 대역) 안에 박아둔 "원본 촬영분 (얼굴 컷) 자리"
     드로텍스트 라벨을 완전히 제거할 것. 지금은 fade 제거로 안 보이게만
     막아뒀지, 근본적으로 소스에서 없애야 함.
   - 영상(B-roll) 위에 얹는 대형 타이포가 흐릿하다는 피드백 — 현재
     soft-shadow(\blur) 방식으로는 부족. 또렷하게 나오는 방법을 더
     찾을 것 (배경 밝기 감지 후 그림자 강도 자동 조절 등 고려).
   - Pexels 등에서 가져오는 B-roll 클립 자체를 사람이 보기 전에 한 번 더
     검수하는 절차 필요 (엉뚱한 국가 간판이 보이는 등 — 외국인환자
     프로젝트의 홍콩공항 클립 사례).
   - design_reference.md §7 (2026-07 추가 스터디)에 정리된 픽토그램/
     그래픽 패턴을 `assets_lib.py`/`render.py`에 반영 — 막대그래프 필
     형태, 오브젝트 아이콘 비교 클러스터, 부지 강조용 항공사진 오버레이,
     빅넘버 좌측정렬/푸티지 위 직접 노출 배리에이션. §7 끝의
     "다음 구현 시 반영할 것" 4개 항목이 체크리스트.

3. 사용자 실제 영상(9~11분)으로 전체 파이프라인 첫 실전 — 긴 영상에서
   구간/커버리지/전사 품질 점검
4. premiere.xml 을 실제 프리미어에서 가져오기 검증 (경로 relink 흐름)
5. 쇼츠(세로 1080x1920) 렌더 프로파일 실작동 테스트 (config에 구조만 있음)
6. BGM 덕킹, 원커맨드 실행 등 (사용자와 논의된 후보)

## 대화 톤 참고

사용자 호칭 없음/반말 섞임, 빠른 실행 선호. "어떻게 하라는거야" = 설명이
복잡했다는 뜻이니 클릭 단위로 다시. 스크린샷을 자주 보내니 이미지로 안내.
