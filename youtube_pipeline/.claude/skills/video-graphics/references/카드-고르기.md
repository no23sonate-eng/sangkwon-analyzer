# 문장의 종류 → 그래픽의 종류

대본 문장을 읽고 **먼저 이 표에서 종류를 찾는다.** 소재는 그다음이다.
예문은 전부 올리브영 성수편 실제 나레이션.

## 1. 값 · 수치

| 문장이 이러면 | 카드 | 비고 |
|---|---|---|
| 값 하나를 던진다<br>"541억 5,290만원에 낙찰됐다" | `BigStatsCard` | 값이 결론이면 `hot`. 도해 옆에 붙는 값은 `item.chip` 으로 색 박스에 넣는다 |
| 값이 A에서 B로 바뀐다<br>"감정가 396억이 541억이 됐다" | `StrikeSwapCard` | 앞 값에 취소선, 아래로 화살표 |
| 값이 쌓여 총액이 된다<br>"취득세까지 하면 570억" | `CostStackCard` | 층층이 쌓인다 |
| 순위·추이 | `RankTrendCard` · `TrendCard` | |

## 2. 견주기

| 문장이 이러면 | 카드 | 비고 |
|---|---|---|
| 두 값의 크기 차이<br>"감정가 396억 vs 낙찰가 541억" | `ShapeCompareCard` | 추상 막대. **막대 위에 숫자 올리지 않는다** |
| 여러 **건물**을 견준다 | `SilhouetteCompareCard` | 실제 형상 실루엣. 아는 건물이 하나 섞이면 축척이 공짜로 생긴다. **높이 출처가 없으면 쓰지 않는다** |
| 같은 면적, 다른 모양 | `AspectRatioCard` · `FrontageCard` | 평면 vs 입면 |
| 주체별로 전략이 다르다 | `YTableCard` | 이름 칸 폭 고정, 값은 그 옆 |

## 3. 인과 · 흐름

| 문장이 이러면 | 카드 |
|---|---|
| A 때문에 B, B 때문에 C<br>"건물주가 바뀌면 → 수익률 개선 → 임대료 인상" | `YFlowCard` |
| 절차가 단계로 간다<br>"소송 → 법원 → 공개 입찰" | `TimelineRailCard` · `PaperFlowCard` |
| 시간 순 | `CalendarCompareCard` · `TimelineBarsCard` |

## 4. 선택 · 갈래

| 문장이 이러면 | 카드 | 결정적 차이 |
|---|---|---|
| 둘 중 **하나를 고른다**<br>"따라갈지, 만들지" | `ForkPathCard` | 줄기가 둘로 갈라진다 |
| **둘 다** 살아 있다<br>"임대 수익과 브랜드 효과, 동시에" | `TwoPanelCard` | 좌우 무게가 같다 |

이 둘을 바꿔 쓰면 안 된다. 실제로 한 번 섞어 놔서 같은 그림이 두 번 나갔다.

## 5. 구조 · 배분  ← **가장 값이 나가는 자리**

| 문장이 이러면 | 카드 |
|---|---|
| 크기 때문에 **못 하는 것**이 있다<br>"층고가 낮으면 큰 조형물을 못 세운다" | `SectionScaleCard` |
| 전체가 **무엇에 먹히는가**<br>"197평이라 자주식 주차가 쉽지 않다" | `AreaBudgetCard` |
| 대지 형상·면적 | `SitePlotCard` |
| 매스·볼륨 | `MassingCard` · `IsoDiagramCard` |
| 층별 구성 | `Floor3DCard` · `SectionDiagramCard` · `LayerPeelCard` |
| 지분이 나뉜다 | `ShareSplitCard` |

## 6. 위치

| 문장이 이러면 | 카드 |
|---|---|
| 어디인가 · 얼마나 가까운가 | `MapCard` |
| 넓은 지역 분포 | `GeoMapCard` |

## 7. 근거 · 자료

| 문장이 이러면 | 카드 | 비고 |
|---|---|---|
| 기사에 이렇게 적혀 있다 | `ArticleCard` | 한글은 재조판, 원문 증거력이 필요하면 `shot` |
| 자료(사진·렌더·도면)를 보여 준다 | `MediaPlateCard` | 판 위에 얹는다. 조감도처럼 **아직 없는 것**은 반드시 이쪽 |
| 실사 위 한 곳을 짚는다 | `AnnotatedShotCard` + `caps` | 곡선 화살표가 대상을 정확히 |
| 두 장을 나란히 | `SplitProofCard` · `BeforeAfterCard` |

## 8. 장면 · 전환

| 문장이 이러면 | 카드 |
|---|---|
| 장면 자체가 주인공 (거리, 사람, 매장) | `LowerThirdCard` (full-bleed) |
| 장이 바뀐다 · 안(案) 이름 | `PlanTitleCard` |
| 크게 한마디 | `HeadlineCard` · `YHeadlineCard` |

---

## 고르고 나서 반드시 확인

1. **같은 카드가 세 컷 연속인가?** → 하나를 다른 종류로 바꾼다
2. **`LowerThirdCard` 가 전체의 절반을 넘는가?** → 설명 문장을 소재로 때우고 있다
3. **설명 문장인데 그림이 뜻을 안 지는가?** → 5번 구간에서 다시 고른다
4. **바탕 테마가 연속 세 컷 같은가?** → paper / ink / blueprint 를 돌린다
