# 규칙과 함정

전부 **실제로 당한 것들**이다. 추측으로 적은 항목은 없다.

## 파이프라인 함정

### 카드는 두 곳에 등록한다
`motion/src/cardRegistry.jsx` **와** `motion/src/Root.jsx` 양쪽.
한쪽만 하면 **오류 없이 조용히 빠진다.** 스틸은 MotionWrap 을 거쳐 통과하기
때문에 검수에서도 안 걸린다. 실제로 두 컷이 그렇게 사라졌다.

### 렌더는 한 번에 하나만
`scripts/render_all.sh` 가 `flock` 으로 막는다. 앞 렌더가 도는데 새로 시작하면
`clips` 를 지우고 들어가 앞 렌더의 QA 가 깨지고 51프레임짜리 미리보기가 나온다.

### 돌고 있는 셸 스크립트를 고치지 않는다
bash 는 파일을 바이트 오프셋으로 읽는다. 편집하면 `unexpected EOF` 로 죽는다.

### 한글 프로젝트명은 `pgrep -f` 로 못 잡는다
프로세스 목록에서 한글이 깨져 매칭에 실패한다. **스크립트 이름만으로** 잡는다.
(대기 루프가 즉시 빠져나가 렌더 도중에 다음 단계가 돌았다)

### `scene_plan.json` 의 `start` 는 나레이션 기준이다
실제 렌더 길이와 다르다 — 한 번은 27초 어긋났고 마지막 여섯 컷이 영상 밖
시각을 가리켰다. **컷 시트 프레임은 완성 영상에서, 실제 클립 길이를 누적한
시각으로** 뽑는다 (`scripts/frames_from_preview.py` 방식).

### 작업 폴더가 되돌아갈 수 있다
컨테이너가 재시작되면 렌더 산출물(gitignore 대상)이 통째로 사라진다.
**소스와 커밋은 원격에 올려 두면 살아남는다.** 산출물이 사라졌으면 원격에서
소스를 맞추고 다시 렌더하는 수밖에 없다 — 다시 *작업*하는 게 아니라 다시 *뽑는* 것.

## 검수는 눈이 아니라 재서 한다

123컷을 눈으로 훑으면 반드시 몇 개를 놓친다. 실제로 놓쳤다.

    python3 scripts/qa_check.py <프로젝트>
    python3 scripts/check_contrast.py <프로젝트> --frames <프레임폴더>
    python3 scripts/learn_refs.py <이미지폴더> --out <출력>   # 레퍼런스 측정

- **글자 대비** — 흰 베일이 얇으면 검정 글자가 사진에 묻힌다. 글자 뒤 밝기
  195 미만이면 scrim 을 올린다
- **중복 자막** — 소재를 갈아 끼우며 라벨까지 복사한 자리가 생긴다.
  화면만 보면 안 보이고 **나레이션과 나란히 놓아야** 드러난다
- **소재 중복** — `props.media` · `bg.backdrop` · `broll.src` 를 **한 이름
  공간에서** 센다. 한 곳만 세면 중복이 남는다

## 소재 규칙

- 같은 소재를 두 번 쓰지 않는다 (0중복이 기준)
- 계열(밤/거리/매장/갤러리/사무실/돈/현장)은 맞춰 바꾸되,
  **고유명사가 찍힌 소재는 자리에서 못 움직인다.** 젠틀몬스터 매장 사진을
  다른 컷으로 옮기면 그냥 이상한 그림이다
- Pexels 는 검색이 403 이지만 **다운로드는 열려 있다.**
  ID 를 웹검색으로 구해 `scripts/fetch_pexels.py --video <id>` 로 받는다
- 구글 이미지 검색은 이 환경에서 **못 쓴다** (curl 은 JS 껍데기, 브라우저는
  프록시를 못 뚫는다). **네이버 이미지 검색은 curl 로 열린다** —
  `scripts/fetch_naver_images.py`. 한 번 "사진이 없다" 고 결론지었다가 틀렸다.
  검색이 막힌 게 아니라 **경로를 잘못 골랐던 것**이다

## 좌표 규칙

- 지도 핀은 **주소를 확인하고 그 주소를 지오코딩**한다. 눈대중으로 찍으면
  성수처럼 블록이 100m 인 동네에서 다른 블록에 찍힌다 (여섯 중 다섯이 그랬다)
- 같은 대상이 여러 지도에 나오면 **좌표를 상수 하나로 묶는다.**
  따로 두면 한쪽만 고쳐서 같은 매장이 두 자리에 찍힌다

## 납품

- 프리미어: `scripts/build_premiere_xml.py` — **계획서를 안 믿고** clips 의
  실제 파일과 길이를 재서 이어 붙인다
- 파일 전송 한도는 **30MB**. 큰 꾸러미는 **각각 따로 열리는 zip** 여러 개로
  나눈다. `zip -s` 분할은 맥 기본 압축 프로그램이 못 연다
