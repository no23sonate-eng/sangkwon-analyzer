# 내 컴퓨터에서 실행하기 (비개발자용)

한 번만 설치하면, 이후엔 명령 한 줄로 웹앱이 열립니다.

## 1회 설치

### 맥 (macOS)
1. **터미널** 앱을 엽니다 (Spotlight에서 "터미널" 검색)
2. 아래를 한 줄씩 붙여넣고 엔터 (중간에 비밀번호를 물으면 입력):
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install python ffmpeg git
git clone https://github.com/no23sonate-eng/sangkwon-analyzer.git
cd sangkwon-analyzer && git checkout claude/youtube-editing-pipeline-khz454
pip3 install -r youtube_pipeline/requirements.txt
```

### 윈도우 (Windows)
1. **PowerShell**을 관리자 권한으로 엽니다 (시작 → "powershell" 검색 → 우클릭 → 관리자)
2. 아래를 한 줄씩 붙여넣고 엔터:
```powershell
winget install Python.Python.3.12 Gyan.FFmpeg Git.Git
# PowerShell 을 껐다 다시 켠 후:
git clone https://github.com/no23sonate-eng/sangkwon-analyzer.git
cd sangkwon-analyzer; git checkout claude/youtube-editing-pipeline-khz454
pip install -r youtube_pipeline/requirements.txt
```

### API 키 설정 (공통, 1회)
`youtube_pipeline/.env` 파일을 만들고 (메모장으로) 아래 내용 저장:
```
PEXELS_API_KEY=발급받은_키
PIXABAY_API_KEY=발급받은_키
ANTHROPIC_API_KEY=발급받은_키   # 없으면 이 줄 생략 (휴리스틱 모드로 동작)
```

## 매번 실행

터미널(맥) / PowerShell(윈도우)에서:
```bash
cd sangkwon-analyzer
python3 youtube_pipeline/app.py     # 윈도우는 python youtube_pipeline/app.py
```
→ 브라우저에 http://localhost:8500 이 자동으로 열립니다.

## 사용 순서

1. 영상 업로드 (프로젝트 이름 입력)
2. **① 전사** 실행 → 끝나면
3. **② B-roll 검색** 실행 → **후보 고르기** 버튼으로 검토 페이지에서 선택·저장
4. **③ 자막** 실행 → **자막 검토**에서 수정·확정 저장
5. **④ 렌더** 실행 → output.mp4 다운로드 (완성본 미리보기)
6. **⑤ 내보내기** 실행 → **프리미어/캡컷 패키지(zip)** 다운로드
   - `premiere.xml`: 프리미어에 드래그 → B-roll이 배치된 시퀀스 생성
   - `subtitle.srt`: 자막 가져오기 (프리미어/캡컷 공통)
   - `typo/*.png`: 대형 타이포 — 오버레이 트랙에 드래그
   - 자세한 건 zip 안의 `가이드.txt`

## 자주 묻는 문제

- **전사가 처음에 오래 걸림**: 첫 실행 때 음성인식 모델을 내려받아서 그렇습니다 (1회만)
- **B-roll 검색 실패**: .env 의 PEXELS/PIXABAY 키 확인
- **최신 코드로 업데이트**: `cd sangkwon-analyzer && git pull`
