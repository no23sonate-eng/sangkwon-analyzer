# 디자인 레퍼런스 — 지식 교양 채널 편집 체계

> 셜록현준·조승연의 탐구생활 16개 영상(스토리보드 ~2,300프레임) + 본인 채널 4편을
> 분석해 추출한 디자인 시스템. style_guide.md 의 운영 규칙이 여기서 나온다.
> 새 컴포넌트(그래프·카드 등)를 만들 때 이 문서를 기준으로 한다.

## 1. 대원칙

1. **자막은 작고 균일하다.** 크기로 소리치지 않는다. 전 구간 같은 크기,
   위계는 색·박스·타이포 카드로 만든다.
2. **자료는 액자에 담는다.** 사진·문서·지도는 풀블리드가 아니라
   배경 캔버스 위 카드로. 여백이 고급스러움을 만든다.
3. **타이포와 자료화면은 겹치지 않는다.** 대형 타이포는 얼굴샷 위 전용.
4. **모션은 없다.** 컷과 크로스페이드, 사진의 느린 줌뿐.
   화려함 대신 정확한 레이아웃과 색.
5. **한 화면 한 메시지.** 인포그래픽 카드도 수치 하나, 비교 하나만.

## 2. 색 체계 (실측값)

### 본인 채널 기본
| 용도 | 값 |
|---|---|
| 본문 자막 | #FFFFFF |
| 강조 (시그니처) | #FAFF2E 레몬 옐로 — 강조 전용, 배경 금지 |
| 프레임 배경 (밝은 자료) | #EFEAE3 웜 페이퍼 |
| 프레임 배경 (어두운 자료) | #16181D 딥 차콜 |

### 인포그래픽 카드 팔레트 (셜록현준 실측 — 그래프/카드 제작 시)
| 용도 | 값 |
|---|---|
| 카드 배경 | #104030 딥 포레스트 그린 (또는 #16181D 차콜) |
| 지도/면 요소 | #307060 뮤트 민트그린 |
| 포인트(아이콘·강조 도형) | #C0392B 벽돌 레드 |
| 텍스트 하이라이트 박스 | #7FD8C0 민트 (문서 인용 시 핵심 문장 위) |
| 카드 위 텍스트 | #FFFFFF / #EDEDE4 |

- 카드 하나에 포인트 색 1개만. 배경-면-포인트 3단 구조.
- 본인 채널로 가져올 때: 카드 배경은 차콜/딥그린 유지, 포인트는
  레몬 옐로(#FAFF2E)로 치환 가능 — 단 하이라이트 박스와 병용 금지.

## 3. 텍스트 컴포넌트

### 3-1. 본문 자막 (모든 발화)
- 얇은 웨이트, 작게(1080p 기준 40px), 항상 한 줄, 하단 중앙.
- **타이트 다크 박스**: 글자에 딱 붙는 반투명 검정 박스(투명도 약 70~75%).
  두 채널 공통의 가독성 장치 — 어떤 배경에서도 읽힌다.
- 강조 단어만 레몬 옐로. 문장당 최대 2개.

### 3-2. 대형 키워드 타이포 (얼굴샷 전용)
- headline: 얇은 웨이트 초대형(84px), 화이트 — 질문/핵심 구문
- concept: 미디엄 웨이트(64px), 레몬 옐로 — 외국어 개념어·수치
- **concept 는 한국어 소형 설명을 아래 병기** (조승연 패턴):
  "High-end Blight" 큰 글씨 + 그 아래 "고급의 악영향" 작은 화이트(34px)
- 화면 중앙, 페이드 250ms, 노출 2.5~3초

### 3-3. 명칭 라벨 칩 (향후)
- 인물/건물/브랜드 소개 시 좌상단 작은 칩: 다크 박스 + 흰 이름
  + 포인트색 밑줄 or 사이드바 (셜록 패턴)

### 3-4. 타임라인 (향후)
- 가로 선 + 점, 세리프/얇은 라벨 (조승연 패턴). 다크 footage 위 화이트.

## 4. 자료화면 연출

- **사진/스틸**: 배경색 캔버스 + 흰 테두리(6px) 카드, 화면 높이 74%,
  카드 내부만 Ken Burns. 배경은 자료 밝기로 자동 (웜페이퍼/차콜).
- **문서/기사 인용**: 다크 카드 위 문서 스크린샷 + 핵심 문장에
  민트 하이라이트 박스 + 하단에 번역/요약 자막 (셜록 패턴).
- **지도**: 플랫 라인/면 지도. 다크그린 배경 + 민트 면 + 지명 크게.
  실사 위성지도 금지 (톤 깨짐).
- **두 장 비교**: 카드 두 개 나란히 (좌우 각 42% 폭), 같은 배경 캔버스.
- **아카이브 영상**: 풀블리드 허용 (질감 자체가 무드).

## 5. 리듬

- 얼굴샷 5~15초 ↔ 자료/B-roll 2~5초 교차. 오프닝은 얼굴샷.
- 인포그래픽 설명 구간은 길어도 됨(10초+) — 단 카드 안 요소가 단계적으로
  추가되는 방식(빌드업)이며 카메라 움직임은 없음.
- 나레이션은 쉼 없이 밀도 높게. 자막은 발화와 1:1 싱크.

## 6. 하지 않는 것

- 키네틱 타이포, 흔들림, 급줌, 화려한 트랜지션, 파티클
- 원색 대비 남발 (포인트 1색 원칙)
- 자막 2줄, 대형 글씨 남발
- 자료 위 대형 타이포
- 스톡 느낌 기업 홍보 클립

## 7. 픽토그램·데이터 그래픽 세부 스타일 (2026-07 추가 스터디)

> 셜록현준 6개 영상 스토리보드(약 600프레임: 부산/요코하마, 도쿄/서울,
> 벤치, 2026 신축건물 리뷰) 재분석. 조승연 채널은 팝업스토어·온천 2편도
> 함께 봤으나 픽토그램 활용은 셜록현준 쪽이 압도적으로 많음.

### 7-1. 막대그래프 — 끝이 둥근 필(pill) 형태
- 막대 상단이 **직각이 아니라 둥글게(캡슐 모양)** 마감된다 — 딱딱한 사각
  막대보다 부드러운 인상. `bar_chart()` 다음 개선 시 반영 대상.
- 강조 막대(보통 마지막/최신 값) 1개만 포인트색, 나머지는 회색조 면색
  (기존 원칙과 동일) — 단 막대 폭이 좁고 간격도 좁아 촘촘한 느낌.
- 제목은 카드 좌상단에 작게, 그 바로 아래 더 작은 회색 서브텍스트(단위 등)
  — 지금 구현과 일치, 유지.

### 7-2. 오브젝트 아이콘 비교 클러스터 (신규 패턴)
- 단색 실루엣 픽토그램보다 **미니 아이소메트릭(입체감 있는) 오브젝트
  일러스트**를 쓰는 빈도가 높다 (예: 차량+통 vs 도시락+선물박스 비교).
- 비교 대상을 **2~3개씩 그룹으로 묶고, 그룹 사이에 얇은 세로 구분선**을
  그어 좌/우(또는 좌/중/우) 비교 구도를 만든다.
- 각 그룹 아래에 작은 라벨 텍스트. 카드 배경은 기존 인포그래픽 팔레트
  (딥그린/차콜) 그대로.
- 스케일 비교(피라미드 등 크기 비교) 시 작은 사람 실루엣을 옆에 두어
  크기 감을 준다 — "사람 대비 크기" 아이콘은 계속 활용 가치 높음.

### 7-3. 도넛/파이 차트 — 카드가 아니라 오버레이
- 지금까지 가정한 "카드 안에 그래프"와 달리, 도넛 차트는 **어두워진
  실사 푸티지 위에 직접 오버레이**로 뜨는 경우가 많다 (풀스크린 카드
  아님, 화면 한쪽에 작게).
- 가는 **리더라인(leader line)**으로 수치 라벨을 차트 밖으로 빼서 연결.

### 7-4. 특정 부지·건물 강조 — 항공사진 + 반투명 하이라이트 오버레이
- §4 의 "실사 위성지도 금지"는 **국가/도시 단위 지도**에 한정된 규칙.
- 특정 필지·건물·구역을 설명할 때는 오히려 **실사 항공사진 위에 대상
  구역만 반투명 포인트색으로 덧칠**하는 연출을 쓴다 (스톡 느낌 대신
  실제 자료 사진 자체가 신뢰도를 준다). 국가 단위는 플랫 지도,
  부지 단위는 항공사진+오버레이로 구분해서 써야 함.

### 7-5. 대형 숫자(빅 넘버) — 카드 없이 푸티지 위 직접 오버레이도 허용
- 지금 구현은 항상 화면 중앙에 카드처럼 뜨는데, 실제로는 **실사 푸티지
  위에 배경 없이 직접** 뜨는 경우도 많다: 작은 라벨(장소명 등, 작고
  연한 녹색) → 큰 숫자 → 하단에 캡션 한 줄, 3단 구성.
- 항상 중앙 정렬은 아니고 **좌측 정렬**도 흔하다.

### 7-6. 인증·뱃지형 아이콘 (신규)
- 신뢰도를 강조할 때 트로피·메달·문서 아이콘을 골드 톤으로 작게
  조합해서 쓴다 (예: 인증서 아이콘 + 메달 아이콘 + 작은 인물 실루엣).

### 다음 구현 시 반영할 것 (실행은 보류 — 스터디만 완료)
1. `assets_lib.bar_chart()`: 막대 상단 라운드 처리(pill 형태)
2. `assets_lib.py`에 오브젝트 아이콘 비교 클러스터 생성 함수 (그룹+구분선)
3. 특정 부지 강조용: 실사 이미지 위 반투명 포인트색 폴리곤/사각 오버레이
   생성 함수 (국가 단위 `flat_map`과는 별도 함수로)
4. 대형 숫자 디스플레이에 "푸티지 위 직접, 좌측 정렬" 배리에이션 추가
   (현재는 항상 중앙 카드형 1종류뿐)
